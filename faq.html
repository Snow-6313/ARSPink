Help Center

Everything you need to understand the Criminality layout, profile loader, and local catalog.

If you want the visuals adjusted, open Discord and say whether you want the palette, spacing, or loader card changed.

Access and Layout

Is the site connected to any game?

No. This is a static site concept and there is no game connection in the code.

What makes the homepage different?

The homepage is split into a bold copy column and a live Discord profile loader for the featured ID.

Is the loadout board static?

Yes. The old API-driven feed was replaced with local Criminality loadout data.

Homepage and Loader

What ID is loaded on the homepage?

The featured profile uses Discord ID 511514401262796815.

What happens if the profile request fails?

The card falls back to the supplied name and initial while keeping the layout intact.

Is the motion effect heavy?

No. It is intentionally noticeable but kept under control so the page feels polished instead of noisy.

Profile and Security

Can I change the featured profile?

Yes. Swap the Discord ID in the homepage card if you want a different profile loader target.

What if I want a different layout style?

Open Discord and describe the palette or composition changes you want. The structure is easy to retheme.

Is the site tied to any account system?

No. There is no login or account backend attached to this version.

Site Notes

Is any of this live data?

Only the Discord profile lookup is live. Everything else is intentionally local and static.

Why is there no external feed?

The site was rewritten to avoid the old executor API and keep the concept self-contained.

Can I reuse this layout for other games?

Yes, but this version is intentionally scoped to Criminality only.

Does the site work on mobile?

Yes. The new layout is responsive and keeps the profile loader readable on smaller screens.
